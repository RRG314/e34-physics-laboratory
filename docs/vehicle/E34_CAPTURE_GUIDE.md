# Owner-reference capture guide

Owner photographs and measurements will replace uncertain geometry without blocking the current laboratory.

## Preparation

- Use a level surface and normal tire pressure.
- Remove personal identifying material from the scene.
- Include a rigid scale bar or known-size checker target in each measurement series.
- Keep focal length fixed where possible; record camera and lens metadata.
- Photograph overcast outdoors or in diffuse light to reduce reflections.

## Exterior priority set

1. Full left, right, front, and rear views with the camera centered at body mid-height and as far away as practical.
2. Front and rear three-quarter rings at approximately 15-degree increments.
3. Roof, hood, trunk, rocker, bumper, lamp, grille, mirror, and glass close-ups.
4. Wheel and tire straight-on views, tire markings, measured wheel diameter, hub center height, and track widths.
5. Wheelbase, overall length, body width reference points, sill height, and wheel-arch gaps.

## Technical areas

- Engine bay: overall grid plus overlapping detail passes with hood reference points.
- Underbody: lift-only, professionally supported; systematic front-to-rear strips with scale.
- Suspension/wheel wells: ride height, steering straight and at lock, unloaded condition only when safely lifted.
- Interior: dashboard orthographic-like views, seating, controls, pedals, trunk, and door openings.
- Components: photograph before removal, record orientation and mount-point distances, then capture all faces.

## Safety

Do not enter an unsupported vehicle, work under the factory jack, run the engine in an enclosed space, touch hot/high-current systems, or disassemble safety-critical components merely for data capture. Existing service work is the preferred opportunity for inaccessible photographs.

## Data handoff

Each capture folder should include date, VIN/build-month redacted as desired, market, transmission, options affecting geometry, camera metadata, measurement method, uncertainty, and a text map connecting image names to component IDs.
