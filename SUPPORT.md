# Getting help

Use a GitHub issue when you can provide a reproducible software problem, a specific documentation error, or a concrete research question related to the project.

Before opening an issue:

1. Read the [project status](docs/PROJECT_STATUS.md) and [documentation index](docs/README.md).
2. Search open and closed issues for the same question.
3. Confirm that you are using Node.js 22 or later and installed dependencies with `npm ci`.

This project cannot provide mechanical repair advice, vehicle safety approval, professional engineering certification, or individual tutoring. For a suspected security problem, follow [SECURITY.md](SECURITY.md) instead of posting details publicly.
